Root cause of the headline failure

Autonomous execution is dead because the pg-boss queue is never created. pg-boss v10 requires createQueue() before send/work; the repo has zero. DB proof: the job table is empty and the autonomous_task_execution queue doesn't exist. So "Team is working..." shows forever and nothing runs. One-line fix in taskExecutionPipeline.ts:909. This single gap disables background execution, handoffs, approval cards, the run tree, and peer-review-on-execution.
