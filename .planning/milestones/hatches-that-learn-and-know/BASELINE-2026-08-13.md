## 4. The improvement protocol (how we prove it got better, not just different)
1. This file is the frozen "before." Do not edit its numbers; add a new dated baseline file after changes.
2. After a phase ships, re-run the SAME commands and record a new dated file.
3. Improvement = the delta vs this baseline, per metric, in the right direction. A structural metric (section 1) must not regress; a quality metric (section 3) must rise; the internet probe (section 2) must flip to YES.
4. For a specific capability (RAG, the learning loop, web-learning), use the A/B form: run the benchmark with it ON vs OFF and report the delta. That A/B delta, sliced by role and controlled for provider, is the only proof of "smarter" that cannot be asserted. Ties to MEAS-05/06 and the evidence protocol in `COVERAGE-AND-EVIDENCE.md`.
