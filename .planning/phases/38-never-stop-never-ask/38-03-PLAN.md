Live vibe-check on 2026-07-09 confirmed the general directive gets overridden by her exploratory opener template. Fix: append a Maya-specific override block AFTER the general directive so the LLM reads the commit-shape rule last.

Purpose: Close ALWY-05 per CONTEXT.md Post-Vibe-Check discovery #3. Preserves the general directive, generic-agent behavior, and non-autonomous Maya behavior byte-for-byte. Additive-only change.
</objective>

## Task 1 — Add MAYA_AUTONOMOUS_OVERRIDE constant to server/ai/promptTemplate.ts

Sibling to AUTONOMOUS_DIRECTIVE_BLOCK. Content per pre-flight brief. XML-wrapped for the LLM to parse as a scoped block. Explicitly names the exploratory phrase Maya must NOT open with ("I keep coming back to...") so the model has a concrete pattern to suppress, and gives the commit-shape example so the model has a concrete pattern to emit.

## Task 2 — Extend PromptBuilderProps + buildSystemPrompt

Add `agentIsSpecial?: boolean` to PromptBuilderProps. In buildSystemPrompt, when the existing `autonomyLevel === 'autonomous'` branch fires, also check `agentIsSpecial` and append `MAYA_AUTONOMOUS_OVERRIDE` after `AUTONOMOUS_DIRECTIVE_BLOCK`.

## Task 3 — Thread agentIsSpecial through openaiService.ts

Add `agentIsSpecial?: boolean` to ChatContext. Both createPromptTemplate sites (streaming + intelligent-response paths) forward `context.agentIsSpecial` into PromptBuilderProps.

## Task 4 — Wire chat.ts to source the flag from respondingAgent

Read `respondingAgent?.isSpecialAgent` and set on chatContext before the generateStreamingResponse call. A nullish agent leaves the field undefined (Maya only responds when she's the selected agent, so this is the tight path).

4. generic + confirm → contains neither

Exit 0 on 4/4 pass, 1 on any fail.
